# Жизненный цикл чата

**Правило: один чат = одно исполнение скилла.** Скилл отработал — чат закрывается, следующий скилл стартует в новом чате. Передача — через [handoff-protocol.md](handoff-protocol.md).

Граница чата = граница артефактов на диске. Всё, что нужно следующему чату, лежит в `DOCS_ROOT/` (и в git). Переписка между чатами **не переезжает** — что важно, фиксируй в файл до закрытия чата.

## Почему не «один чат на эпик / на Story»

Раньше зона = чат (весь эпик в одном чате, вся Story в одном). Контекст переполнялся к концу зоны. Теперь дроблёж до уровня скилла: каждый шаг стартует с чистого контекста, читает артефакты с диска, делает свою часть, готовит хендофф.

## Что переезжает между чатами

**Без потерь (на диске / в git):**
- `DOCS_ROOT/<epic-slug>/` — PRD, preview, tech-spec, arch-review, market-research
- `DOCS_ROOT/<epic-slug>/stories.md` — файловый бэклог эпика (Stories + Tasks + статусы), ведёт `agile-coach`
- `DOCS_ROOT/<feature-slug>/` — user/support/analytics документация
- feature-ветки и worktree'и (см. [worktree-protocol.md](worktree-protocol.md))
- `CLAUDE.md`, `_shared/`, memory

**С потерями:** переписка, нюансы устного обсуждения. Нужно сохранить — в файл/`stories.md` **до** закрытия чата.

## Короткие чаты (без хендоффа в следующий скилл)

Standalone-скиллы — каждый свой короткий чат, заканчивается обычным результатом, не хендофф-блоком:
- `epic-legal-review` — по запросу
- `tracker-sync` — по запросу
- `analytics-insights` — через 1–2 недели после релиза
- `pipeline-retro` — мета-ретро
- любой `marketing-*`
- `agile-coach` в режимах стендап / груминг / прогресс / приоритеты

## Параллельная работа

Можно вести несколько чатов одновременно: параллельные эпики, параллельные Story одного эпика, параллельные Task одной Story (если orchestration-граф в `stories.md` помечает их parallel). Изоляция — через worktree'и и git-ветки.

**Нельзя:** два чата редактируют один файл в одной ветке, не зная друг о друге. Граф зависимостей в `stories.md` — источник правды о том, что параллелится.

## Когда дробить чат внутри длинного скилла

Длинный скилл сам себя не дробит. Но если внутри одного скилла пауза 30+ минут с тяжёлыми ответами (prompt cache выгорел) — допустимо закрыть чат, зафиксировав состояние в артефакт, и продолжить в новом.
