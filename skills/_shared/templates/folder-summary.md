# Шаблон: summary-README папки материалов

> Шаблон из библиотеки скиллов. Копируй структуру, не файл.
> Назначение: «что здесь происходит и где искать материалы» — для человека и для агента.
> Эталоны в бою: `x5transport/Продукты/дизайн-система/README.md`,
> `x5transport/Продукты/ЦП/лояльность/00 README — навигация и резюме.md`.
> **Конвенция: файл ≤100 строк.** Имя файла: `README.md` (или `00 README — навигация и резюме.md`
> в Obsidian-папках, чтобы сортировался первым).

```markdown
# <Папка> — что здесь и где искать

<1-3 строки: что за материалы, к какому продукту/задаче относятся, текущее состояние.>

## Содержимое

| Файл / папка | Что внутри | Для кого |
|---|---|---|
| <имя> | <полстроки> | <владелец / разработчик / агент> |

## Статус и пробелы

- <что готово / согласовано>
- <что не сделано и почему — честно>

## Связи

- <ссылки на смежные папки, PRD, _wiki-разделы — относительными путями>
```
