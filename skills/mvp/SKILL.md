# MVP — быстрый проход за один заход

Один чат: бриф → сборка → результат. Без discovery-шагов и PRD.
Опирается на [tracks.md](../_shared/tracks.md) (TRACK=fast), [mode.md](../_shared/mode.md),
[communication-style.md](../_shared/communication-style.md).

## Шаг 1 — бриф (всегда, даже если «и так понятно»)

Пользователь описывает, что хочет получить, — свободно, без Job/AC-формализма.
Уточни только то, без чего нельзя строить (обычно ≤3 вопросов одним сообщением).

Зафиксируй `brief.md` в папке задачи (папка проекта или бакет x5t — определил kickoff;
если kickoff не было — определи сам по правилам его шага 2):

```markdown
# Бриф — <название>
- TRACK: fast · MODE: <app|work>
- Что решаем: <1-2 строки своими словами пользователя>
- Скоуп: <что входит>
- НЕ делаем: <что осознанно за бортом>
- Готово, когда: <критерий простым языком>
```

Бриф — рабочий артефакт, не согласование: написал → показал одной строкой → строишь.
Ждать ✅ не нужно, если пользователь не попросил.

## Шаг 2 — сборка по MODE

**MODE=app (свой продукт):** сразу код. Минимальный работающий вариант, без
Clean Architecture-церемоний — но код честный: работает, не падает, секреты не светятся.
Смоук-прогон → деплой по DEPLOY_* из project-config → боевой URL пользователю.
Деплой на прод — ⏸ покажи результат локально/превью и дождись ✅ (это единственный гейт).

**MODE=work (X5 и подобное):** кликабельный прототип — статичный HTML (+Tailwind CDN)
или лёгкий Vite, по правилам `epic-preview`. Для X5 — стиль X5 Drive
(читать `Продукты/дизайн-система/STYLE-GUIDE.md`). Выкладка на превью-URL по ситуации.

## Шаг 3 — результат

Короткий итог на бизнес-языке: что готово, где смотреть, что осознанно не сделано (из брифа).
Без хендоффа — fast-трек заканчивается результатом.

Если по ходу выяснилось, что задача больше «одного захода» — скажи прямо и предложи
апгрейд трека: бриф становится входом для `epic-prd` (трек `prd`) — ничего не выбрасывается.

## Принципы

- Скорость важнее полноты, но артефакт (бриф) — всегда: след «что и зачем делали».
- Никакого discovery: не исследуем рынок, не строим граф работ, не пишем PRD.
- Один гейт — перед боевым деплоем/сдачей. Остальное — без остановок.
