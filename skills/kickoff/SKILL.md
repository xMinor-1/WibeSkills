# Kickoff — роутер входа в задачу

Лёгкий скилл маршрутизации: 4 вопроса → запись решения → передача в первый скилл.
Без методологии в теле. Опирается на [tracks.md](../_shared/tracks.md), [mode.md](../_shared/mode.md),
карту pipeline в [handoff-protocol.md](../_shared/handoff-protocol.md).

## Когда НЕ запускаться (правило обхода)

- Сообщение называет конкретный скилл («запусти epic-prd…», «прогони тесты») → сразу туда.
- Сообщение — хендофф-промпт (slug эпика + пути к артефактам) → сразу в названный скилл;
  TRACK/MODE читаются из `epic-meta.md` эпика.
- Продолжение уже идущей работы в том же чате → не вклиниваться.

## Шаги

Вопросы задавай компактно — одним-двумя сообщениями, не анкетой.

**1. Что за результат.** Пользователь описывает свободно, что хочет получить. Без формализма
Job/AC — просто понять суть и масштаб.

**2. Где живёт задача.** Три варианта:
- **Существующий проект** → работаем в нём (project-config уже есть).
- **Новый отдельный проект** → подтвердить одной строкой («это отдельный проект, заводим папку?»),
  создать `projects/<slug>/` + скелет `CLAUDE.md` (по [templates/project-claude.md](../_shared/templates/project-claude.md))
  + `.claude/project-config.md` (копия шаблона, заполнить ЯДРО из ответов).
- **Подзадача X5 Транспорт** → отнести к бакету **СРМ / ЦП / Сайт х5т**
  (карта — `x5transport/Продукты/CLAUDE.md`); артефакты пойдут в папку бакета.

**3. MODE** — из `project-config.md` проекта. Для нового проекта — спросить одной строкой
(«код до прода веду я или отдаём живому разработчику?»).

**4. TRACK** — предложить с дефолтом (см. [tracks.md](../_shared/tracks.md) § Дефолты):
X5-продукт → `enterprise` · side-проект → `indie` · «уже продумал, опишу требование» → `prd` ·
«набросать быстро» → `fast`. Пользователь переопределяет одним словом.

**5. Зафиксировать и роутить.**
- Записать выбор в `DOCS_ROOT/<epic-slug>/epic-meta.md` (формат — в tracks.md § Персистентность).
  Для `fast` вместо epic-meta достаточно шапки `brief.md` (её создаст скилл `mvp`).
- Хендофф в первый скилл по карте pipeline:
  `fast` → `mvp` · `prd` → `epic-prd` · `indie`/`enterprise` → `market-research` (или сразу
  `epic-prd`, если ценность очевидна) · «есть stories.md, погнали кодить» → `delivery-run`.

## Хендофф

Стандартный блок по [handoff-protocol.md](../_shared/handoff-protocol.md). Промпт обязан включать:
скилл, slug, путь к epic-meta.md, TRACK и MODE.

## Принципы

- Роутер решает «куда», не «как» — никакой методологии, никаких требований здесь.
- Всегда остаётся артефакт решения (epic-meta.md или бриф) — выбор не живёт в памяти чата.
- Сомневаешься между треками — предложи более лёгкий и скажи, что апгрейд возможен
  (fast → prd → indie/enterprise: бриф дорастает до PRD, не наоборот).
