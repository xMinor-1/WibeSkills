# pipeline-retro — журнал

Каждый запуск `pipeline-retro` добавляет запись сюда.

Формат:

```
## YYYY-MM-DD
- До: NNNN строк / ≈MM токенов
- После: NNNN строк (−Δ%)
- Сделано:
  - <правка 1>
  - <правка 2>
- Отложено / не сделано:
  - <причина>
- Гипотеза на следующее ретро: <что проверить>
```
