# Юр-чеклисты по нормам

Прогоняй только **релевантные** блоки выбранного режима (`LEGAL_REGIME` из project-config). Нерелевантное — пропусти явно: «реклама — не применяется, эпик не вводит рассылки».

Файл содержит три пресета: **РФ**, **GDPR** (стартовый), **generic**. Используй пресет своего режима; при необходимости адаптируй под конкретику `LEGAL_NOTES`.

# Пресет: РФ

## Фильтр релевантности (РФ)

| Аспект эпика | Нормы |
|---|---|
| Сбор/хранение ПДн (имя, телефон, email, паспорт, фото, мед.) | 152-ФЗ |
| Дети до 18 как пользователи | 436-ФЗ + усиление 152-ФЗ |
| Email/SMS-рассылки, push, маркетинг | 38-ФЗ + 152-ФЗ |
| Платежи / приём денег | 54-ФЗ + ЗоЗПП + ГК |
| Контрагент-самозанятый | 422-ФЗ + ГК (агентская/комиссия) |
| Подписание документов онлайн | 63-ФЗ |
| Cookies, веб-аналитика, фингерпринты | 152-ФЗ + Минцифры |
| Контент, видео, программы | ГК ч.4 |
| Чаты, отзывы, UGC | 149-ФЗ + 436-ФЗ |
| Отказ в услуге, возвраты, споры | ЗоЗПП |
| Хранение ПДн вне РФ | 152-ФЗ ст.18 (**жёсткий блокер**) |

## 152-ФЗ — персональные данные (договорная и процедурная часть)
- [ ] Все категории ПДн перечислены и классифицированы (общие / специальные / биометрические)
- [ ] Цель обработки сформулирована и совпадает с уведомлением в РКН
- [ ] Согласие на обработку: где собирается, как формулируется, отделено от согласия на рекламу
- [ ] Политика конфиденциальности покрывает новые категории/цели
- [ ] Уведомление в РКН — нужно ли подавать/обновлять
- [ ] Договор-поручение с контрагентом покрывает новые операции (если применимо)
- [ ] Процедура реакции на запросы субъектов ПДн (доступ, изменение, удаление)
- [ ] Процедура уведомления РКН об инциденте за 24 часа
- [ ] Срок хранения ПДн определён, есть процедура удаления

## 152-ФЗ ст.18 — локализация ПДн (блокер)
- [ ] Вся первичная запись ПДн происходит на серверах в РФ
- [ ] Все используемые сервисы (рассылка, аналитика, push, SMS) — российские либо имеют российскую инсталляцию
- [ ] Если есть передача за рубеж — отдельное согласие и страна в списке адекватной защиты

## 436-ФЗ — защита детей (если применимо)
- [ ] Возрастная маркировка интерфейса/контента
- [ ] Согласие законного представителя для ПДн ребёнка до 14 лет
- [ ] Запрет вредной информации в UGC (модерация)

## ЗоЗПП — права потребителей (услуга/оплата/возврат)
- [ ] Существенные условия услуги описаны в оферте до заключения договора
- [ ] Цена, срок, порядок отказа от услуги — явно
- [ ] Информация об исполнителе (реквизиты) доступна
- [ ] Процедура возврата соответствует ст. 32 ЗоЗПП

## 54-ФЗ — онлайн-кассы (если есть приём денег)
- [ ] Чек формируется и отправляется покупателю при каждом расчёте
- [ ] Если касса не у нас (агент/маркетплейс) — кто фискальный агент, прописано в оферте
- [ ] Самозанятый сам формирует чек НПД через «Мой налог», мы не подменяем

## 38-ФЗ — реклама (если рассылки/push/маркетинг)
- [ ] Согласие на получение рекламы — отдельное от согласия на ПДн (галочка отдельная, не предзаполненная)
- [ ] Способ отписки в каждом сообщении (один клик)
- [ ] Реестр согласий: кто, когда, какой канал, каким способом дал согласие

## 422-ФЗ — самозанятые (если контрагенты регистрируются как НПД)
- [ ] Оферта/договор не превращает самозанятого в работника (нет признаков трудовых отношений по ст.15 ТК)
- [ ] Если принимаем деньги от его клиентов и переводим ему — агентская схема прописана
- [ ] Чеки НПД формирует самозанятый сам; если автоматизируем — через официальное API ФНС

## 63-ФЗ — электронная подпись (если онлайн-подписание)
- [ ] Какой тип ЭП используется (простая/усиленная) и достаточен ли он
- [ ] Соглашение об использовании простой ЭП заключается до подписания основного документа

## Cookies / веб-аналитика / трекеры
- [ ] Информирование пользователя о cookie/трекерах (баннер/политика)
- [ ] Если запись ввода в формы (Webvisor-подобное) — поля с ПДн исключены (mask) или собрано отдельное согласие

## ГК ч.4 — авторское право (если контент)
- [ ] Кому принадлежит контент, созданный в продукте (автору? с лицензией нам?)
- [ ] Если показываем чужой контент — есть лицензия

## 149-ФЗ — информация в сетях (UGC, чаты, отзывы)
- [ ] Процедура удаления противоправного контента по запросу
- [ ] Возможность блокировки пользователя

# Пресет: GDPR (стартовый — адаптируй под проект)

- [ ] Lawful basis для каждой операции обработки определён (consent / contract / legitimate interest)
- [ ] Privacy Policy покрывает новые категории данных и цели
- [ ] Data Processing Agreement с субпроцессорами актуален
- [ ] Data subject rights реализованы: access, rectification, erasure, portability
- [ ] Consent — granular, не предзаполнен, легко отозвать
- [ ] Data localization / transfer mechanism (SCC, adequacy decision) для трансграничной передачи
- [ ] Breach notification процедура (72 часа)
- [ ] DPIA проведён для high-risk обработки
- [ ] Cookie consent banner до установки non-essential cookies

# Пресет: generic (нет особого режима)

- [ ] Terms of Service и Privacy Policy актуальны для новых данных/функций
- [ ] Согласие на аналитику/трекинг собрано
- [ ] Авторские права на используемый контент (изображения, шрифты, видео, библиотеки) — лицензии чисты
- [ ] Возрастные ограничения, если продукт может использоваться детьми
- [ ] Договорные условия услуги/оплаты описаны до покупки
